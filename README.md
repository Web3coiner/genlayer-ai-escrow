# GenLayer AI Escrow

## Overview

GenLayer AI Escrow is a smart contract prototype that demonstrates how Intelligent Contracts can improve traditional escrow systems with AI-assisted dispute resolution.

## Features

- Secure escrow deposits
- Buyer confirmation
- Seller payout
- Refund workflow
- AI-ready dispute resolution
- Built for the GenLayer ecosystem

## Vision

This project explores how AI-powered smart contracts can automate trust and decision-making in decentralized applications.
